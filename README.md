## 🛠️ How to Customize Personal Details

Everything personalized is located in one easy-to-edit file:
👉 **`src/data/shivaniData.ts`**

Open [src/data/shivaniData.ts](file:///c:/Users/Ankush/OneDrive/Desktop/AAA/src/data/shivaniData.ts) in your editor:
- **Change Names & Nicknames**: Edit `shivaniConfig`.
- **Edit Letters**: Edit `lettersData` array.
- **Change Photos & Captions**: Edit `scrapbookMemories` (or upload photos directly via the web UI!).
- **Edit Quiz Questions**: Edit `quizQuestions`.
- **Add Reasons**: Edit `reasonsSpecial`.
- **Change Floating Reminders**: Edit `randomLoveMessages`.

## 🚀 Running the Website

To start the local development server:
```bash
npm run dev
```
Open **`http://localhost:5173`** in your browser.

To create an optimized production build:
```bash
npm run build
```
The output will be placed in the `dist/` directory, ready to deploy to Vercel, Netlify, or GitHub Pages.
